# Model Card — Sepsis Early-Warning Classifier

## Intended use
Decision-support risk score to prioritize clinician review of ICU patients
for early sepsis workup. **Not** a standalone diagnostic and not intended to
trigger automated treatment. Human review is required before any clinical
action.

## Training data
Synthetic ICU cohort generated by `data/generate_data.py` (~39,000 6-hour
windows across 6,500 simulated stays), modeled on MIMIC-IV's variable
structure. For real-world use, retrain on a PhysioNet-DUA-governed MIMIC-IV
or eICU extract with the same feature schema.

## Metrics (synthetic test split)
See `models/evaluation_report.json` for the exact numbers from the last
training run — typically AUC-ROC ≈ 0.87-0.89, sensitivity ≈ 0.75-0.80 at
90% specificity.

## Limitations
- Synthetic training data does not capture the full heterogeneity of real
  ICU populations, comorbidities, or documentation practices.
- No external validation cohort is included in this repo; the deck's plan
  calls for eICU external validation before any real deployment.
- The model outputs a probability, not a diagnosis; thresholds must be
  tuned locally against the deploying unit's staffing capacity for alert
  response.

## Fairness audit (checklist — run before deployment)
- [ ] Stratify AUC-ROC and calibration by age band, sex, and (if available)
      documented ethnicity/deprivation index.
- [ ] Check alert-burden parity across ICU units/shifts.
- [ ] Re-run temporal validation after any change to the local EHR/vitals
      capture pipeline.
